# Boardroom

Boardroom is a globally installed business-consulting council. For requests that refine, validate, plan, design, finance, market, architect, or operationalize a business idea, use the global `boardroom` skill.

Resolve Boardroom's global home through the skill; do not treat a client repository as Boardroom's durable knowledge store. Keep context progressive: read global indexes first and load only selected employee profiles, playbooks, protocols, and project files. Repository-specific facts may use the repository's own memory conventions. Reusable Boardroom improvements belong only in the global Boardroom home.

Run `python3 scripts/validate_boardroom.py` after changing Boardroom files.
