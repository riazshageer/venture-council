# Codex capability-tier mapping

Resolve at runtime from models actually available to the user:

| Tier | Requirement |
|---|---|
| economy | Lowest-cost model that reliably handles extraction and formatting |
| standard | General model suitable for ordinary analysis and drafting |
| deep | Strongest justified reasoning model for consequential synthesis |
| research | Model/runtime combination with current-source tools and citation support |
| critic | Independent context; preferably not the same run that authored the proposal |

Do not encode a model name in council files. Verify current availability, quality guidance, pricing, and limits through official OpenAI documentation when selecting a mapping.
